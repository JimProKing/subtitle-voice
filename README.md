# 자막소리

극장 스크린의 한글 외곽선 자막을 카메라로 읽어, 기기에 있는 한국어 TTS로 바로 들려주는 접근성 웹앱입니다.

영상은 브라우저 메모리에서만 처리하고 바로 버립니다. 서버로 화면을 올리지 않습니다. Railway는 웹페이지와 OCR 언어팩만 제공합니다.

## 로컬 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다. 카메라 권한은 HTTPS 또는 localhost에서만 됩니다.

## Railway 배포

1. 이 폴더를 GitHub에 올립니다.
2. [Railway](https://railway.app)에서 New Project → GitHub repo.
3. Dockerfile이 있으면 그대로 빌드됩니다. 공개 URL은 HTTPS라 폰 카메라가 됩니다.
4. 배포 후 폰 브라우저로 열고, 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 극장에서

1. 이어폰을 끼고 휴대폰을 스크린이 가득 차게 고정합니다.
2. **카메라로 시작**을 누릅니다.
3. 조준이 끝나면 **미리보기 끄기** 또는 **극장 모드**.
4. 자막이 뜨면 읽고, 다음 문장이 오면 이전 읽기를 끊습니다.

테스트할 때는 홈의 **테스트 영상으로 시작**에 한글 자막이 박힌 영상 파일을 넣으면 됩니다. 파일도 기기를 떠나지 않습니다.

## 1차 범위

요구사항 파일 기준입니다.

- 아래 자막 우선, 없을 때만 위
- 흰/밝은 글자 + 어두운 테두리, 검은 띠를 가정하지 않음
- 같은 문장 반복 금지, 다음 문장이면 즉시 중단
- 기본 속도 1.15배, 시작/정지/속도/지금 목소리 변경
- 배역명(`이름:`)은 목소리 매핑에만 사용
- `(한숨)`, `♪` 같은 기호는 읽지 않음
- VoiceOver / TalkBack로 조작 가능하게 큰 버튼, 라이브 영역, 단축키
- 오프라인: 한 번 불러오면 서비스 워커가 앱 껍데기와 언어팩을 캐시

아직 넣지 않은 것: 배우 클로닝, 영어 ASR, 번역, 화면해설, 계정, 자막 파일 다운로드, 화면 중앙 전면 OCR.

## 웹 1차의 한계

나중에 네이티브 앱으로 갈 때 채워질 부분입니다.

- 화면을 끈 채 카메라 유지는 웹에서 불가합니다. 대신 화면이 꺼지지 않게 유지합니다.
- OCR은 iOS Vision / Android ML Kit가 아니라 브라우저 Tesseract입니다. 전처리로 외곽선 자막을 뽑은 뒤 해당 구역만 인식합니다.
- 초당 8~12회 전체 OCR 대신, 초당 10회 변화 감지 후 자막이 안정되면 OCR 1회입니다. 목표 지연은 안정 후 0.25~0.40초이지만 기기 성능에 따라 OCR 자체가 더 걸릴 수 있습니다.
- 한국어 목소리 6~10개는 기기에 그만큼 없을 수 있어, 있는 한국어 목소리 + 높낮이 8칸으로 배역을 나눕니다.
